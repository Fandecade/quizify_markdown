# Quizify Markdown 语法规范（AI 批量制卡版）

面向对象：需要批量生成 Anki 卡片的 AI / 脚本。
目标产物：一个 UTF-8 的 `.md` 文件，导入 Quizify Markdown 后同时能在电脑端和
手机端（AnkiDroid / AnkiMobile）正常显示。

对应版本：Quizify Markdown 2.1.x，批量导入格式 `Quizify Card Markdown v1`。

来源依据：`quizify_addon/importer/parser.py`（文件解析）、
`src/shared/syntax-tools.js`（编辑器语法）、
`src/review/markdown/parsers.js`、`src/review/markdown/extensions.js`（渲染）。

---

## 0. 给 AI 的硬性规则（先读这 12 条）

1. 输出 UTF-8 纯文本，换行用 `\n`，不要写 BOM。
2. 文件第一段非空正文必须是独占一行的 `+++`。
3. 每张卡片 = `+++` + `Front` + 独占一行 `***` + `Back`，文件末尾自动结束最后一张。
4. 每张卡片必须有非空 `Front`，并且**恰好一个** `***`。
5. `+++`、`***` 必须顶格写、独占一行；不要缩进、不要加别的字符。
6. 图片必须引用**Anki 媒体库里的文件名**（例如 `网络协议栈.png`），
   绝对不要写 `C:\...`、`/Users/...`、`./assets/...` 或任何本地路径。
7. 默认把 `deck`、`tags` 写在 YAML front matter 里，不要每张卡重复写。
8. Quizify 语法块（`;;;` `===` `:::` `::::`）必须顶格独占一行，前后留空行。
9. 任何要展示给用户看的“语法原文”，放进围栏代码块里（代码块内不解析语法）。
10. 正文里若需要字面的 `+++` / `***`，写成 `\+++` / `\***`。
11. 不确定的语法不要写；宁可写成普通 Markdown，也不要写出不合法结构（会整块退化成纯文本）。
12. 不要生成 `QuizifyID`、不要试图更新/删除已有笔记，v1 导入格式只负责新建。

---

## 1. 两个层级，别混淆

| 层级 | 作用 | 位置 | 谁会解析 |
| --- | --- | --- | --- |
| L1 文件格式 | 把文件切成一张张卡片，指定牌组/标签/媒体 | 整个 `.md` 文件 | Quizify 导入器 |
| L2 字段语法 | 卡片内的交互组件与排版 | `Front` / `Back` 字段内 | 复习运行时 |

L2 的语法写在 L1 切出来的字段里，两者可自由组合。

---

## 2. L1：批量导入文件格式

### 2.1 文件骨架

```markdown
---
quizify:
  format: 1
  deck: 学习::网络
  tags: [网络, 每日]
---

+++
# 这张卡的标题
TCP 的默认端口是 {{80}}。
***
## 解析
传输层协议 TCP 使用 80 端口提供 HTTP 服务。
```

- YAML front matter 可选，且只能出现在**文件最开头**。
- 文件中间的 `---` 是普通 Markdown 分隔线，不会开始新的 YAML。
- YAML 只支持：缩进映射、块列表、行内列表 `[a, b]`、简单标量。
  不支持 anchor/alias、tag、块标量 `|`/`>`、flow mapping `{a: b}`。

### 2.2 文档配置键

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `format` | 整数 | `1` | 只接受 `1`，其他值整个文件被拒绝 |
| `deck` | 非空字符串 | 无 | 默认牌组；`::` 表示子牌组 |
| `tags` | 字符串列表 | `[]` | 加到文件内所有卡片；**标签不能含空格** |
| `media.local` | `copy`/`keep`/`error` | `copy` | 本地媒体处理方式 |
| `media.remote` | `keep`/`error` | `keep` | 远程 URL 处理方式 |
| `media.roots` | 相对路径列表 | `[]` | 显式声明媒体子目录 |

未知的 Quizify 键会产生警告并被忽略（方便发现拼写错误）。

### 2.3 卡片配置

`Front` 的第一个非空块可以是 HTML 注释形式的卡片配置：

```markdown
+++
<!-- quizify-card
deck: 学习::网络::TCP
tags: [TCP, 重点]
draft: false
-->
TCP 三次握手的第二步是什么？
***
服务器回复 SYN + ACK。
```

| 键 | 类型 | 合并规则 |
| --- | --- | --- |
| `deck` | 非空字符串 | 卡片值覆盖文档值 |
| `tags` | 字符串列表 | 文档标签在前，去重合并 |
| `draft` | 布尔 | `true` 时只预览不导入 |

配置注释会从 `Front` 中移除；其他 HTML 注释保留为正文。

### 2.4 媒体引用（最容易出错的地方）

v1 识别的写法只有两种：

```markdown
![说明文字](文件名.png)
![说明文字](<文件名 含空格.png>)
```

规则：

- 路径必须是**相对于 Markdown 文件**的相对路径，且不能含 `..`、不能是绝对路径。
- `media.local: copy`（默认）会把文件复制进 Anki 媒体库，并把字段里的路径
  **改写成 Anki 返回的最终文件名**。这是唯一能让手机上看到图片的方式。
- 围栏/行内代码、HTML 注释、公式块里的图片语法**不会**被当作媒体。
- **不识别**：reference-style 图片 `![a][ref]`、Obsidian embed `![[a.png]]`、
  任意 `<img src>` HTML 标签。要显示图片就用上面的行内写法。

> ⚠️ 高频坑：在字段里写 `![](C:/Users/me/图片.png)` 或 `![](./assets/图片.png)`，
> 导入后手机端只会显示一段路径文字。正确写法是先把图片放进 Anki 媒体库，
> 字段里只写 `![](图片.png)`。

### 2.5 去重与提交行为

- 默认按规范化后的完整 `Front + Back` 去重，两者完全相同就跳过。
- 任何读取/解析/媒体预检错误会阻止**整批**提交；警告不会。
- 牌组创建 + 笔记写入合并为一个撤销项；媒体文件不参与撤销。

## 3. L2：字段内语法总览

| 语法 | 写法 | 类型 |
| --- | --- | --- |
| 填空 | `{{答案}}` | 行内 |
| 单选 / 多选 | `;;;` … `;;;A` | 块 |
| 点击揭示 | `[[题干\|\|答案]]` | 行内 |
| 悬浮批注 | `[术语]^(解释)^` | 行内 |
| 折叠块 | `::: 标题` … `:::` | 块 |
| 标签页 | `=== 标题` … `===` | 块 |
| 文字遮盖 | `%%文字%%` | 行内 |
| 图片 | `![说明](文件名.png)` | 行内 |

加上标准 Markdown：标题、列表、表格、引用、代码块、链接，以及
`**粗体**`、`*斜体*`、`` `行内代码` ``、`~~删除线~~`、`==高亮==`、
`X^2^` 上标、`H~2~O` 下标、KaTeX（行内 `$...$`、块级 `$$...$$`）、
GFM 提示框 `> [!NOTE]`（类型限 NOTE / TIP / IMPORTANT / WARNING / CAUTION）。

所有 Quizify 组件都必须**顶格、独占一行**开始；行首缩进或加文字会让它失效。

## 4. 各语法精确规则

### 4.1 填空 `{{答案}}`

- 单行内成对出现，两侧各两个半角花括号：`HTTP 默认端口是 {{80}}。`
- 答案会 `trim()`，可含空格与标点，但**不能跨行**、不能嵌套 `{{}}`。
- 每处填空渲染为一个输入框 + 一个“揭示答案”按钮，互不影响。

反例：`{{ 80 }}`（会 trim 成 `80`，可用但不推荐）、`{{80`（缺右括号，原样显示）。

### 4.2 单选 / 多选

```markdown
;;;
A. TCP
B. HTTP
C. HTML
;;;B
```

- 开始标记必须是**整行**的 `;;;`（行尾空白允许）。
- 选项行格式：`字母.` + 可选空格 + 描述，例如 `A. 选项` 或 `A.选项`。
  字母为单个 ASCII 字母；描述不能为空。
- 结束标记必须是整行的 `;;;答案字母`，如 `;;;A`、`;;;ABD`；字母不区分大小写。
- **合法性要求（缺一即整块退化为普通文本）**：
  - 选项 ≥ 2；
  - 选项字母不重复；
  - 每个选项描述非空；
  - 答案里的每个字母都存在于选项中。
- 一个正确字母 = 单选；多个正确字母 = 多选，全部选对才算对。
- 选项里可以写行内 Markdown 与公式；围栏代码块、公式块中的 `;;;` 不参与解析。

常见错误：`;;; A. 选项`（开始行多写了内容）、`;;;a` 当作答案（少了选项行）、
选项写成 `1. 选项`（必须是字母）。

### 4.3 点击揭示 `[[题干||答案]]`

- 同一行内写成 `[[题干||答案]]`，`||` 是分隔符，左右都不能为空。
- 不能跨行；题干/答案内不要再写 `[[`。
- 渲染为可点击展开/收起的下划线文字。

### 4.4 悬浮批注 `[术语]^(解释)^`

- 单行：`TCP 是[面向连接]^(发送前需先建立连接)^的协议。`
- 术语不能为空、不能含 `[` 或换行；解释不能为空、不能含换行。
- 括号是半角 `]^(` 与 `)^`，全角 `】^（` 不识别。

### 4.5 折叠块

```markdown
::: 点击查看解析
三次握手 = SYN → SYN/ACK → ACK。
:::
```

- 开始标记：`:::` + **至少一个空格** + 非空标题。
- 结束标记：整行的 `:::`。
- 支持嵌套（内层同样以 `::: 标题` 开始、`:::` 结束）。
- 内部可以是任意 Markdown，包括公式、代码块、列表。

### 4.6 标签页

```markdown
=== 概念
TCP 提供可靠、有序的字节流传输。

=== 对比
UDP 更轻量，但不保证可靠。
===
```

- 开始标记：`===` + 至少一个空格 + 非空标题。
- 下一个 `=== 标题` 开始新标签页；整行 `===` 结束整组。
- 标题与内容均支持行内 Markdown。

### 4.7 文字遮盖 `%%文字%%`

```markdown
TCP 是一种 %%面向连接%%、可靠的 %%传输层协议%%，用 %%三次握手%% 建立连接。
```

- 行内语法：`%%` + 非空文字 + `%%`，可以写在段落、标题、列表、表格单元格里。
- 中间**不能换行**，也不能再出现 `%`。
- 必须成对；一行里 `%%` 出现奇数次时诊断会提示“没有配对”，该行按普通文本渲染。
  如果两个 `%%` 分别落在相邻两行，诊断会直接提示“不能跨行”。
- 渲染为绿色遮盖块：点一下揭示，再点一下重新盖上；同一张卡里多个遮盖块互不影响。
- **答案面默认全部揭示**：翻到背面（显示答案）时，遮盖块自动展开成正常文字，因为
  答案已经揭晓，没有继续遮挡的必要；此时再点一下仍可重新盖上做自测。
  正面（题干）始终保持遮盖。
- 里面可以放**任意行内 Markdown**，遮盖时会连同它自带的颜色和底色一起藏起来：
  行内代码 `%%`npm run build`%%`、加粗 `%%**重点**%%`、
  链接 `%%[文档](https://example.com)%%`、高亮 `%%==标记==%%`、公式 `%%$x^2$%%`。
  揭示后这些样式会原样恢复，不会因为遮盖而丢格式。
- **代码块（多行 ``` 围栏）不能被遮盖**：遮盖是行内语法，一行放不下。需要遮代码时，
  要么改成行内代码 `` `xxx` ``，要么把整段代码拆成几行行内代码逐行遮盖。
- 不要放进链接标签 `[%%文字%%](url)` 或图片说明 `![%%文字%%](img.png)`：
  在 `<a>` 内部它会保持字面文本，避免出现嵌套控件。

### 4.8 图片

```markdown
![网络协议栈](网络协议栈.png)
```

- 文件名必须是 Anki 媒体库里的名字（不含路径）。
- 想让手机也看到，必须先确保媒体文件进入媒体库：
  桌面导入 `.md` 时 `media.local: copy` 会自动复制；
  单独加图片可用 `工具 → Quizify Markdown → 导入图片到媒体库…`，
  或把文件拖进 `collection.media` 再“检查媒体”。

### 4.9 提示框与其余 Markdown

```markdown
> [!WARNING]
> 修改牌组前请先备份数据。
```

- 类型固定为 `NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION`，不区分大小写。
- `[!类型]` 必须写在引用块第一行且独占该行，后续 `>` 行是内容。
- 普通嵌套列表会自动渲染为可折叠大纲，不需要额外语法。

## 5. 合法性、退化与报错速查

| 情形 | 结果 |
| --- | --- |
| `;;;` 块不合法（选项 < 2、字母重复、答案字母不存在） | 整块当普通文本渲染 |
| `;;;` 块没有 `;;;答案` 结尾 | 整块当普通文本渲染 |
| `::: 标题` 没有 `:::` 结尾 | 当普通文本渲染 |
| `%%` 数量为奇数（未配对） | 提示诊断，该行按普通文本 |
| 两个 `%%` 分别在相邻两行 | 提示“不能跨行”，两行都按普通文本 |
| `%%文字%%` 中间含换行或 `%` | 不生成遮盖块，原样显示 |
| 用 `%%` 包住多行 ``` 代码块 | 不生成遮盖块；遮盖是行内语法 |
| `[[a]]`（没有 `\|\|`） | 原样显示 |
| `{{` 未闭合 | 原样显示 |
| 媒体写成绝对路径或含 `..` | 导入前报错，阻止整批提交 |
| 文件缺少首个 `+++` | 解析报错 |
| 某张卡缺 `***` 或 `Front` 为空 | 解析报错（整个文件不导入） |
| 空 `Back` | 允许，但产生警告 |
| YAML 使用 anchor/alias/tag/块标量 `|` `>` 或 `{` | 解析报错，阻止整批导入 |

## 6. 常见错误与修正

| 错误写法 | 问题 | 正确写法 |
| --- | --- | --- |
| `;;;;` 或 `;;; A. 选项` | 开始标记必须整行 `;;;` | `;;;` 单独一行 |
| `;;;a)` / `;;;答案：A` | 结束标记格式错 | `;;;A` |
| `;;;` 里写 `1. 选项` | 选项必须用字母 | `A. 选项` |
| `===标题` | 缺少空格 | `=== 标题` |
| `::: 标题` 后没写 `:::` | 没有结束标记 | 补一行 `:::` |
| `%%没配对的遮盖` | 只有一个 `%%` | 补上收尾的 `%%` |
| `%%跨\n行%%` | 遮盖不能跨行 | 拆成多个 `%%…%%`，或写到同一行 |
| 想遮盖多行 ``` 代码块 | 遮盖是行内语法 | 改用行内代码 `` `xxx` `` 逐行遮盖 |
| `%100%%折扣%` | 中间出现 `%` | 改写文字，避免多余 `%` |
| 图片写 `![](./assets/a.png)` | 会被当媒体路径解析，离开目录即报错 | 用相对本文件的 `![](a.png)` |
| 正文里写裸 `***` 想当分隔线 | 会被当结构标记 | 用 `---`，或写 `\***` |

## 7. 完整示例文件（可直接作为 few-shot 模板）

```markdown
---
quizify:
  format: 1
  deck: 学习::网络
  tags: [网络, 每日]
  media:
    local: copy
    remote: keep
---

+++
# 端口
HTTP 的默认端口是 {{80}}，HTTPS 是 {{443}}。
***
应用层协议：HTTP 80、HTTPS 443。

+++
# 三次握手在哪一层
;;;
A. 应用层
B. 传输层
C. 网络层
D. 数据链路层
;;;B
***
传输层。三次握手 = SYN → SYN/ACK → ACK。

+++
# 先想再看
TCP 建立连接前需要做什么？ [[想一想||三次握手]]
***
先完成三次握手，再传输数据。

+++
# 对比 TCP 与 UDP
=== TCP
可靠、有序、面向连接。
=== UDP
轻量、无连接、不保证可靠。
===

+++
# 文字遮盖：传输层要点
TCP 是一种 %%面向连接%%、可靠的 %%传输层协议%%，用 %%三次握手%% 建立连接。
***
- 点遮盖块揭示，再点一次重新盖上
- 多个遮盖块各自独立

+++
# 图片：协议栈
![网络协议栈](网络协议栈.png)
***
图片文件名必须是媒体库里的名字，才能同步到手机。
```

导入方式：桌面端 `工具 → Quizify Markdown → 导入 Markdown 卡片集…`，
选择该文件即可；图片用包装流程（`media.local: copy`）自动复制进媒体库，
再通过 AnkiWeb 同步到手机。

## 8. 生成后自检清单

- [ ] 第一段非空正文是顶格的 `+++`
- [ ] 每张卡都有非空 `Front` 和恰好一个 `***`
- [ ] 每个 `;;;` 都有 `;;;答案`，且答案字母都在选项里、选项 ≥ 2 且字母不重复
- [ ] 每个 `::: 标题` 都有对应的结束行
- [ ] 每行 `%%` 的数量是偶数（成对），且中间没有换行或多余 `%`
- [ ] `=== ` 后有空格和标题，整组以 `===` 结束
- [ ] 所有图片都是**媒体库文件名**，没有绝对路径、`./`、`../`
- [ ] 正文里的字面 `+++` / `***` 已转义为 `\+++` / `\***`
- [ ] 要展示的语法原文都放在围栏代码块里
- [ ] YAML 只用缩进映射 / 列表 / 简单标量，标签不含空格
