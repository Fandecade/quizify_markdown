Quizify 图片遮挡 · 坐标工具

选一张图片，在上面拖拽画出要遮挡的区域，工具会生成可直接粘贴进 Front / Back 字段的 :::: occlusion 语法。 全程离线，图片不会离开你的电脑。

本页面缺少内置的遮挡解析脚本（构建异常）。请在项目里重新运行 npm run build 后刷新。

1 · 图片与区域

选择图片… 还没有区域

先在左上角「选择图片…」，然后在图片上按住拖动即可画出遮挡框。

2 · 卡片信息

3 · 区域顺序（点击备注名可改）

    拖拽图片后，区域会出现在这里。

    4 · 复制到卡片

    • 把复制到的整段文本粘贴进卡片的 Front 或 Back 字段。
    • 坐标是相对图片的百分比，任何尺寸下都会对齐。
    • 手机端复习时点击区域揭示，右下角悬浮控制可「揭示下一项 / 揭示全部」。
