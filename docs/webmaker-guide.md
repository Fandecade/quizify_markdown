# Quizify 离线制卡台（网页版）

一个**双击即用、不需要安装、不需要联网**的制卡页面：左边卡片列表、中间写
`Front` / `Back`、右边实时预览。写完导出 CSV，导入 Anki 就是 `Quizify Markdown`
笔记类型。

它只做一件事：**把 Quizify Markdown 写对**。所以它不需要照片、不打包 `.apkg`、
不上传任何东西——纯文本，因此可以在电脑上制卡，然后在手机 / 平板上直接看到。
跨设备看图这件事本身就不属于纯文本方案，所以这里也不提供图片功能。

---

## 1. 怎么打开

生成一次即可：

```bash
npm run build:webmaker
```

产物在仓库根目录的 `webmaker/`：

```text
webmaker/
├── index.html              ← 双击这个文件
├── app.js                  ← 制卡台本体
├── app.css
├── quizify-preview.js      ← 预览运行时（和 Anki 卡片同一套渲染管线）
├── quizify-preview.css     ← 预览样式，KaTeX 字体已经内嵌成 data URL
├── syntax-tools.js         ← 语法诊断与结构分析
├── quizify-i18n.js         ← 界面词库
├── THIRD_PARTY_LICENSES.md
└── licenses/
```

**直接双击 `webmaker/index.html`**，浏览器地址栏会显示 `file:///...`，这就是预期状态。
整个文件夹可以随意复制、放到 U 盘、丢进网盘，只要能保持文件在一起就行。

- 建议 Chrome / Edge / Safari 的较新版本（需要 `<dialog>`、Shadow DOM、Blob 下载）。
- 不需要本地服务器；页面对 `file://` 做了专门处理：产物全是经典脚本（不是 ES 模块），
  字体全部内嵌，运行时不发起任何网络请求。
- 想更保险，可以在浏览器里收藏这个 `file://` 地址。

## 2. 界面

三栏：**卡片列表 | 编辑区 | 实时预览**。

- 顶栏：牌组名（导出 CSV 的 `#deck:`）、全局标签（`#tags:`）、保存状态、导入、导出。
- 卡片列表：「＋ 新建」加一张，「清空」清空整个牌组（点两次确认）；每行最左边是拖拽手柄
  `⠿`，按住它上下拖动就能调整顺序（鼠标直接拖整行也行），最右边的 `×` 删掉那一张。
  上面的搜索框按正面 / 背面 / 标签过滤，**筛选状态下拖动会被禁用**，先清空搜索再排序。
- 编辑区上方是工具栏：左边 `Markdown` 一组，右边 `Quizify` 一组，点一下就把语法
  插到光标处；选中文字再点，就把选中的文字填进语法的空位。
- 预览栏：正面 / 背面切换、自适应 / 手机宽度（340px，用来核对手机上的排版）、
  主题（开务 / 格致）、明暗（对应 Anki 的日间 / 夜间）、复位交互、全部揭示。
- 底部状态栏：语法诊断、这张卡里可交互结构的数量、正反面字节数。
  诊断有问题的行号会显示在鼠标悬停提示里。

预览是真的交互的：`%%遮盖%%` 点一下揭开、再点一下盖上；填空题能输入；选择题能点。
这就是手机上会看到的效果。

### 手机 / 平板

窄屏（≤900px）下三栏改成**一次只显示一栏**，底部多出一条页签：

- **卡片** —— 列表、搜索、新建、清空、拖动排序、逐张删除，页签上带卡片数量。
- **编辑** —— 正面 / 背面 / 标签；工具栏改成横向滚动，不再堆成好几行。
- **预览** —— 和电脑上完全一样的卡片效果，「复位交互」「全部揭示」变成整行大按钮。

在手机上点列表里的某张卡、或点「＋ 新建」，都会自动跳到「编辑」。牌组名和全局标签在
顶栏输入，导入 / 导出在右上角。横屏平板（≥901px）保持多栏并排。

所有按钮都按手指尺寸放大了，输入框统一 16px 字号（否则 iOS 一聚焦就会把页面放大）。
这个页面可以直接「添加到主屏幕」，它会全屏打开，和 App 一样。

说明：`file://` 下的拖拽、自动保存和导出在手机浏览器里都照常工作；如果要用
「选择文件…」导入，iOS Safari 对本地文件的限制比桌面浏览器多一些，直接粘贴 CSV
文本更稳妥。

## 3. 快捷键

`Mod` 在 macOS 上是 `⌘`，在 Windows / Linux 上是 `Ctrl`。
按 `Mod+/`（或 `?`）随时打开快捷键表，**表里的每一行都可以直接点击执行**，
也可以当命令面板用来搜索；`Mod+K` 直接跳到搜索框，输入后回车执行第一条。

### 文本格式

| 快捷键 | 作用 |
| --- | --- |
| `Mod+B` | 加粗 |
| `Mod+I` | 斜体 |
| `Mod+E` | 行内代码 |
| `Mod+Shift+K` | 链接 |
| `Mod+Shift+X` | 删除线 |
| `Mod+Shift+H` | 高亮 |
| `Mod+Shift+.` | 上标 |
| `Mod+Shift+,` | 下标 |
| `Mod+Alt+A` | 警告框 `> [!NOTE]` |
| `Mod+Alt+T` | 标题 |
| `Mod+Alt+Q` | 引用 |
| `Mod+Alt+U` | 无序列表 |
| `Mod+Alt+O` | 有序列表 |
| `Mod+Alt+C` | 代码块 |

（表格按钮只在工具栏里。）

### Quizify 语法（和 Anki 内编辑器完全一致）

| 快捷键 | 作用 | 插入的内容 |
| --- | --- | --- |
| `Mod+Alt+1` / `Ctrl+Alt+1` | 填空 | `{{答案}}` |
| `Mod+Alt+2` | 选择 | `;;;` A/B/C `;;;A` |
| `Mod+Alt+3` | 揭示 | `[[题干\|\|答案]]` |
| `Mod+Alt+4` | 批注 | `[内容]^(批注)^` |
| `Mod+Alt+5` | 折叠 | `::: 标题` / `内容` / `:::` |
| `Mod+Alt+6` | 标签页 | `=== 标签一` / `内容一` / `===` |
| `Mod+Alt+7` | 文字遮盖 | `%%要遮盖的文字%%` |

选中一段文字再按这些键，选中的文字会直接替换掉模板里的示例文字。
其它指令走 `Mod+Alt+<字母>` 是为了避开 macOS 的 `⌘⌥H/M/D`（隐藏其它 App、
全部最小化、显示程序坞）这类系统级按键。

### 卡片与导航

| 快捷键 | 作用 |
| --- | --- |
| `Alt+1` / `Alt+2` / `Alt+3` | 焦点跳到正面 / 背面 / 标签 |
| `Mod+Enter` | 保存当前卡并新建下一张 |
| `Alt+N` | 新建卡片 |
| `Alt+D` | 复制当前卡片 |
| `Alt+Backspace` | 删除当前卡片（可撤销） |
| `Alt+Shift+Backspace` | 清空全部卡片（可撤销） |
| `Alt+Z` | 撤销删除 |
| `Alt+←` / `Alt+→` | 上一张 / 下一张 |
| `Alt+↑` / `Alt+↓` | 在列表里上移 / 下移 |

`Mod+Z` 只有在焦点不在输入框时才接管，写卡片时它仍然是浏览器自带的撤销。

### 预览与文件

| 快捷键 | 作用 |
| --- | --- |
| `Alt+P` | 预览切换正面 / 背面 |
| `Alt+W` | 预览切换自适应 / 手机宽度 |
| `Alt+R` | 预览里全部揭示 |
| `Alt+Shift+R` | 复位预览交互 |
| `Alt+Shift+G` | 切换主题（开务 / 格致） |
| `Alt+Shift+D` | 切换明暗 |
| `Mod+S` | 导出 CSV |
| `Mod+O` | 打开导入对话框 |
| `Mod+/`、`?` | 命令与快捷键表 |
| `Mod+K` | 命令面板 |

## 4. 用它制卡的完整流程

1. 双击 `webmaker/index.html`。
2. 顶栏填牌组名，例如 `学习::网络`（`::` 是子牌组，Anki 里不存在会自动创建）；
   需要的话再填全局标签。
3. 写正面、写背面。想插入语法就按快捷键或点工具栏；右边随时核对效果。
4. `Mod+Enter` 或「＋ 新建」继续下一张；左边列表可以搜索、切换，
   拖每一行左边的 `⠿`（或 `Alt+↑` / `Alt+↓`）调整顺序。
   每行右侧的 `×` 直接删掉那一张，「清空」删掉整个牌组（点两次确认，只留一张空白卡）；
   删完都能用 `Alt+Z` 或右下角「撤销删除」找回来。
5. `Mod+S` 导出 CSV。文件名形如 `quizify-学习-网络-20261012-2315.csv`。
6. 打开 Anki（桌面端）→ **文件 → 导入** → 选这个 CSV。

因为导出文件的第一段是：

```csv
#separator:comma
#html:false
#notetype:Quizify Markdown
#deck:学习::网络
#columns:Front,Back,tags,guid
#tags column:3
#guid column:4
#if matches:update current
```

所以导入面板会**自动选好笔记类型 `Quizify Markdown` 和牌组**，不需要手动挑。
确认分隔符是「逗号」后点导入即可。

### 反复导入同一份文件不会产生重复卡片

`#guid column:4` 加 `#if matches:update current` 的含义是：Anki 用第 4 列的
`guid` 认卡片，`guid` 相同的卡片会被**更新**而不是新建。所以改完文案再导一次，
手机上同步后就地更新，不会变成两张。

```text
改文案 → 重新导出 → 再导入一次 → 同步 → 手机上是新内容
```

### 备份与迁移

制卡台用浏览器 `localStorage` 自动保存（右上角会显示「已自动保存」）。
它的作用域是「这个浏览器 + 这个文件路径」，换浏览器或清了缓存就没了。
要长期保存或换机器，用导入对话框：

- 「导出」得到的是 CSV，可以再导入进来（当作卡片恢复）；
- 导入对话框同时接受本工具的 **工程 JSON**，格式是
  `{"version":1,"settings":{...},"cards":[...]}`，需要完整备份时用这个更保险。

导入对话框支持两种方式：

- 直接把 CSV / JSON 粘贴进文本框；
- 点「选择文件…」挑一个文件（读进文本框后，再选「追加」或「替换」）。

「追加到现有卡片」会把解析出来的卡片接在末尾；「替换全部卡片」则清空重来。
CSV 里的 `<br>` 和 HTML 实体会被还原成真正的换行——这是为了对接 Anki 里
`#html:false` 的存储格式。

## 5. 它知道哪些语法

状态栏的诊断、结构计数和预览都走 `src/shared/syntax-tools.js`，也就是 Anki
编辑器里那一套。和 `docs/quizify-markdown-spec.md` 完全一致：

| 语法 | 说明 | 定义在哪 |
| --- | --- | --- |
| `{{答案}}` | 填空 | `docs/quizify-markdown-spec.md` |
| `;;;` … `;;;A` | 选择（单选 / 多选） | 同上 |
| `[[题干\|\|答案]]` | 揭示 | 同上 |
| `[内容]^(批注)^` | 批注 | 同上 |
| `::: 标题` … `:::` | 折叠 | 同上 |
| `=== 标签` … `===` | 标签页 | 同上 |
| `%%要遮盖的文字%%` | 文字遮盖（点一下揭示，再点一下盖上） | 同上 |

遮盖里可以放行内 Markdown，遮盖时会连同它自带的颜色和底色一起藏起来：
`%%`npm run build`%%`（行内代码）、`%%**重点**%%`（加粗）、
`%%[文档](https://example.com)%%`（链接）、`%%$x^2$%%`（公式）都能正常遮盖和揭示。

**遮不住的**：多行 ``` 代码块。`%%…%%` 是行内语法，一行放不下；
要么改成行内代码 `` `xxx` ``，要么把代码拆成几行逐行遮盖。
两个 `%%` 写到相邻两行时，状态栏诊断会直接提示“不能跨行”。

**没有**图片遮挡、没有音频、没有随机遮盖——这些是刻意的：纯文本才能多端同步。

## 6. 排错

- **右侧预览是空白 / 写「预览模块没加载成功」**：`quizify-preview.js` 没跟
  `index.html` 放在一起，或者文件夹被拆开了。整个 `webmaker/` 目录要一起复制。
- **打开的是一堆代码 / 下载了文件**：把 `index.html` 拖进浏览器窗口，或右键
  →「打开方式」→ 浏览器。
- **中文变成方块**：预览用的字体来自系统，装一个带中文的字体（macOS / Windows
  默认就有）。
- **刷新后内容没了**：浏览器清过站点数据，或者用了另一个浏览器 / 另一个路径。
- **导出的 CSV 导入后没有自动选中笔记类型**：先在 Anki 里建好
  `Quizify Markdown` 笔记类型（装一次这个加载项就会建）。
- **提示「牌组名不能包含逗号、双引号或换行」**：改掉牌组名里的这些字符，
  否则 CSV 的文件头会被切错。

## 7. 重新构建

```bash
npm run build          # 可读产物：quizify_addon/ 与 webmaker/
npm run build:webmaker # 只重建网页制卡台
node tools/build.mjs --release --webmaker   # 最小化版本（约 1.3 MB）
```

源码在 `src/webmaker/`：

```text
src/webmaker/
├── index.html        # 页面骨架
├── app.css           # 界面样式
├── app.js            # 主程序：三栏联动、工具栏、快捷键、导入导出
├── preview-entry.js  # 预览运行时入口（Shadow DOM + quizify-preview.css）
├── csv.js            # CSV 导出 / 解析 / Anki 转义还原
├── store.js          # 卡片模型、撤销栈、自动保存
├── shortcuts.js      # 快捷键解析（按物理键位匹配，见下）
└── dom.js            # 小工具
```

`shortcuts.js` 用 `event.code` 识别数字键和标点，而不是 `event.key`：
macOS 上 `⌥1` 的 `event.key` 是 `¡`，`⇧.` 是 `>`，用字符判断会全部失效。
`docs/` 里没有别的页面依赖它，改动只影响网页制卡台。
